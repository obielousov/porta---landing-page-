# Porta — Portfolio Website

A fully responsive portfolio website for a product designer featuring a modern dark-themed interface, smooth animations, and interactive UI components.

🌐 Live Demo: https://obielousov.github.io/porta---landing-page-/

## Features

- **Modern portfolio layout** — dark-themed interface with a clean, content-focused design
- **Animated page sections** — scroll reveal effects powered by IntersectionObserver
- **Testimonials slider** — responsive Swiper carousel with touch support
- **FAQ accordion** — semantic details/summary implementation with smooth animations
- **Responsive navigation** — sticky header with a mobile burger menu
- **Accessibility** — semantic HTML, ARIA attributes, prefers-reduced-motion, and noscript fallback

## Tech Stack

- **HTML5** — semantic markup and SEO-friendly metadata
- **SCSS** — modular architecture with reusable partials compiled into CSS
- **Vanilla JavaScript** — framework-free implementation
- **Swiper** — responsive testimonials slider
- **Assets** — SVG icons, optimized images, and local fonts

## Project Structure

```
.
├── index.html          # semantic markup
├── scss/               # SCSS source files
├── css/                # compiled CSS
├── js/                 # site interactions
├── img/                # images & SVG assets
└── fonts/              # local fonts
```

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/obielousov/porta---landing-page-.git
   ```

2. Open `index.html` in any modern browser.

No installation or build process is required.
